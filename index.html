RQ2 — Do Stylometric Features Improve Detection?

{% set ab = results.ablation_tfidf_plus_stylometric %}

Adding the supplementary stylometric features (word count, URL count, urgency-word count, first-person pronoun ratio, lexical diversity, exclamation-mark count) to the best model ({{ ab.model }}) changed F1-score from {{ "%.4f"|format(ab.tfidf_only.f1) }} (TF-IDF only) to {{ "%.4f"|format(ab.tfidf_plus_stylometric.f1) }} (TF-IDF + stylometric) — a change of {{ "%+.4f"|format(ab.f1_gain) }}. {% if ab.adopted_for_app %} This is a meaningful improvement, so the combined feature set was adopted for this prototype. {% else %} This is not a meaningful improvement, so the prototype uses TF-IDF features alone for simplicity and speed. This suggests the hand-crafted stylometric features used here add little beyond what TF-IDF n-grams already capture on this dataset — a genuine, reportable finding for RQ2, not a failure of the approach. {% endif %}

RQ3/RQ4 — Generalisation Across Generation Methods

The dataset contains emails produced by two different generation methods: an LLM fine-tuned for phishing generation, and prompt-engineered generation from a general-purpose LLM. Testing {{ results.best_model }} within vs across these subsets gives a proxy for cross-generator generalisation (the exact concern raised by Chen et al., 2026):
